The colour rule

ColumnShading
All residues identicalred
Non-identical, every pair scoring BLOSUM-62 at or above the thresholdorange
Below the threshold, or any column containing a gapunmarked

Stryer's Biochemistry (5th ed., §7.2) defines a conservative substitution as one scoring > 0, which is the default here. The more inclusive ≥ 0 is sometimes used instead. The choice is not cosmetic, and the threshold in force is reported with the figure.

With three or more sequences, each residue is scored against sequence 1 rather than requiring every pair in a column to qualify, so one outlier no longer blanks its column.

Alignment

Pairs are aligned by Needleman–Wunsch with Gotoh affine gap costs on BLOSUM-62. Three or more sequences are aligned by star alignment anchored on sequence 1, which keeps every column in the reference's coordinates — the same frame the region selection, the residue numbering and the per-residue scoring all use.

Selecting a region can either trim the existing alignment or realign each sequence against the region alone by semi-global alignment, which holds up better when the sequences diverge outside the domain.

Statistics

Per-column conservation is the Henikoff position-weighted share of sequences carrying the commonest residue, so a crowded clade does not outvote a lone outgroup. A selected region is compared against the remainder of the protein with a Mann–Whitney U test, tie-corrected because conservation values cluster heavily at 1.

Structure

Models come from AlphaFold DB by UniProt accession, or from PDB and mmCIF files you supply, which covers AlphaFold 3 output downloaded from the AlphaFold Server. AlphaFold DB itself serves AlphaFold 2 models; no public database serves AlphaFold 3 predictions by accession.

Superposition is quaternion Kabsch over C-alpha pairs taken from the sequence alignment, restricted by default to residues with pLDDT ≥ 70. Fitting over disordered tails makes an RMSD meaningless: for CLK2 against DOA it is 31.7 Å unrestricted and 0.55 Å over the kinase domain.

Data sources

  • UniProt — sequences, search, features, and sequence identification by UniParc checksum
  • InterPro — domain and repeat annotations, including the member databases
  • OMA — orthologues, one entry per species
  • AlphaFold DB — predicted structures

Each is queried directly from your browser. Sequences you paste are never sent anywhere; the only thing that leaves the page for identification is a 16-character checksum.
